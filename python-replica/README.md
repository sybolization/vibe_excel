# Vibe Excel Python

Independent, uv-managed Python implementation of the existing Vibe Excel project.
Core execution and HTML exports require Python and Git, not the original checkout or Node.
The optional pi RPC integration requires Node and pi, as selected for this replica.

```powershell
uv sync --locked
uv run vibectl demo
uv run vibectl status
uv run pytest
```

The complete command reference and implementation boundaries are added with the replica.
